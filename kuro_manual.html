右ペイン
まだ文書が読み込まれていません。

.md ファイル / フォルダをドロップ

単一ファイルなら見出しが項目に、複数ファイルならファイルが項目になります。
左の項目をクリックすると、右ペインが該当箇所へジャンプします。

キーボード操作

J / ↓ / →
次の項目へ
K / ↑ / ←
前の項目へ
1…9
その番号の項目へ直接ジャンプ
⌘F / Ctrl F
全文横断検索
⌘E / Ctrl E
右ペインを 連続 ⇔ ページ で切替
[ / ]
前後のファイルへ（複数読込時）
?
このヘルプ
Esc
閉じる / ハイライト解除

連続モードでは ↑↓ は通常のスクロールに使えます（J / K は常に項目移動）

文書側での指定

title
文書名
levels
項目に拾う見出しレベル（例 [1, 2]）
style
standard / dark / book / api
mode
scroll / page
collapse
下位項目をたたんで開く

.md の先頭を --- で挟んだブロックに書きます（サンプル文書の6章参照）
