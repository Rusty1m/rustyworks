RECOUP MANUAL

Recoup 取説 / Manual

Recoup は、外付けHDD・SSD・SDカード・USBメモリから、削除された写真や動画を復元する macOS 用アプリです。壊れかけのドライブからは、読める分だけを救い出します。

Recoup is a macOS app that recovers deleted photos and videos from external HDDs, SSDs, SD cards, and USB drives, and salvages what is still readable from failing ones.

概要 / Overview

JAPANESE

Recoup はディスクの生データを直接走査し、ファイルシステムが手放した写真・動画を掘り出します。

FAT / exFAT / NTFS / APFS を問わず動作し、フォルダにはもう表示されないファイルも見つけられます。

ENGLISH

Recoup scans the raw disk to dig out photos and videos the file system has let go of.

It works regardless of the file system (FAT / exFAT / NTFS / APFS) and finds files that no longer appear in any folder.

復元元のディスクには一切書き込みません。読み取り専用で開き、復元したファイルは指定した保存先にのみ書き出します。

The source disk is opened read-only and never written to.

動作環境 / Environment

日本語
  • macOS 26 以降
  • Apple Silicon / Intel
  • itch.io で配布
  • 対象：外付けHDD・SSD・SDカード・USBメモリ
  • 復元先として別のディスクの空き容量が必要
  • 生ディスクの走査に管理者パスワードが必要
ENGLISH
  • macOS 26 or later
  • Apple Silicon / Intel
  • Distributed on itch.io
  • External HDDs, SSDs, SD cards, USB drives
  • Free space on a separate disk for recovered files
  • Administrator password required for raw disk access

鉄則 / Ground Rules

1. 気づいたら、書き込みを止める

写真を撮り足したり、ファイルをコピーしたりすると、消えたデータが上書きされて戻せなくなります。復元作業を始めるまで、そのカード・ドライブは使わないでください。

Stop writing to the affected media as soon as you notice. Overwritten data cannot be recovered.

2. 復元先は必ず「別のディスク」

復元元と同じカードに書き込むと、まだ残っているデータを自分で壊してしまいます。Mac の内蔵ドライブや、別の外付けドライブを保存先にしてください。

Always recover to a different disk than the one you are recovering from.

クイックスタート / Quick Start

1. 読み取り元を選ぶ

画面上部で用途を選び、接続中のディスク一覧から対象を選びます。ディスクイメージ（.img / .dmg）を開くこともできます。

2. 保存先を選ぶ

「復元ファイルの保存先」で、復元元とは別のディスクのフォルダを指定します。空き容量が表示されるので確認してください。

3. スキャン開始

生のディスクを読むため、macOS 標準の認証ダイアログで管理者パスワードを求められます。走査が始まると、見つかったファイルがサムネイルで次々と表示されます。

4. 選んで復元

左のフィルタで絞り込み、サムネイルで中身を確認してから、救いたいものを選んで「選択した◯件を復元」を押します。

1. Choose a source disk (or a disk image). 2. Choose a destination folder on a different disk. 3. Start the scan and enter your administrator password. 4. Review the thumbnails, select what you want, and recover.

3つの機能 / Three Tools

削除ファイル復元 / Recover Deleted Files

ディスク全体を走査し、ファイル構造から写真・動画を組み立て直します。いちばんよく使う機能です。数TBのドライブでも中断・再開できます。

救出コピー / Salvage Copy

マウントはできるが調子の悪いドライブから、読めるファイルをコピーします。読めないブロックはその部分だけ飛ばして続行するので、1ファイル丸ごと諦めません。「写真・動画・音声のみ」フィルタを外せば、ファイル種別を問わず退避できます。

ディスクをイメージ化 / Disk Image

異音がする、頻繁に切断されるドライブ向け。一度だけ全体を読んで .img に保存します。作成したイメージは「削除ファイル復元」の読み取り元として使えるので、以降は弱ったドライブに触らずに作業できます。

使い分けの目安

軽症（消しただけ・ディスクは健康）→ 削除ファイル復元
中症（読めるがエラーが出る）→ 救出コピー
重症（異音・切断・大量エラー）→ イメージ化 → イメージに対して復元

結果を見る / Reviewing

見つかったファイルはサムネイルで一覧表示されます。復元する前に、実際に救えているかを目で確認できます。

  • 種類で絞る：写真 / RAW / 動画 / 音声
  • 状態で絞る：良好 / 一部破損
  • 表示切替：サムネイル / リスト（サイズ・オフセット・状態を一覧）
  • ダブルクリック：Finder で表示

右側のインスペクタには、種類・サイズ・ディスク上のオフセット・状態、そして復元できる可能性が表示されます。「一部破損」のファイルは、読める範囲だけがプレビューされます（写真なら上半分だけ、など）。

Filter by kind and status, switch between thumbnail and list view, and check the inspector for size, offset, status, and recovery likelihood before restoring.

中断と再開 / Resume

大容量ドライブの全走査には時間がかかります。Recoup は途中で止めても、続きから再開できます。

進行状況は保存先フォルダの中にscan.progress というファイルとして記録されます。メモリ上ではないので、アプリを終了しても、Mac を再起動・シャットダウンしても、停電で落ちても、続きから再開できます。

再開するときは、前回と同じ保存先フォルダを指定してください。同じ読み取り元を選ぶと「前回の続きから再開」ボタンが表示されます。

⚠️ 再起動をはさむと「再開」ボタンが出ないことがあります

macOS はディスクに disk4 disk6 のような番号を接続順で割り当てるため、再起動や USB 機器の抜き差しで番号が変わることがあります。番号が変わると、アプリが「前回と同じディスク」だと判断できず、再開ボタンが出ません。

このとき、記録した進行状況そのものは失われていません。他の USB 機器をいったん外して対象のディスクだけを接続し直し、元の番号に戻れば再開ボタンが表示されます。

macOS assigns disk numbers in connection order, so a reboot or replugging can change them. If the number changes, the resume button will not appear — your progress file is still intact. Reconnect only the target disk to get the original number back.

「救出コピー」と「イメージ化」も同様に再開に対応しています。救出コピーは同名・同サイズのファイルをスキップし、イメージ化は中断位置を記憶します。

限界 / Limitations

正直にお伝えします。以下は Recoup にできないことです。

  • 上書きされたデータは復元できません。削除後にそのカードを使い続けた場合、失われている可能性が高いです。
  • 物理的に完全故障した媒体（認識すらしない、通電しない）からの復元はできません。
  • ファイル名・撮影日時・フォルダ構造は復元されません。ファイルシステムのメタデータを読まないため、連番の新しい名前が付きます。
  • 断片化した長時間動画は、途中までしか戻らないことがあります。
  • MTS（AVCHD）、FUJIFILM RAF、Olympus ORF はカービング非対応です。

Overwritten data, physically dead media, original filenames/dates/folder structure, and the formats listed above are out of scope.

困ったとき / Troubleshooting

SDカードが一覧に出ない

「更新」を押してください。内蔵 SD カードスロットのカードも表示されます。それでも出ない場合は「内蔵ディスクも表示」を有効にするか、カードを挿し直してください。Finder にも表示されない場合は、カードリーダーやカード自体の問題の可能性があります。

「空き容量が足りません」と出る

保存先ディスクの空きが足りません。別の空きの多いディスクを保存先に選んでください。スキャンは途中から再開できるので、空きを作ってから続きを実行できます。

スキャンが遅い / 時間がかかる

数TBの全走査には時間がかかります。中断しても続きから再開できます。重症のドライブは、先に「イメージ化」してからイメージに対してスキャンする方が、ドライブへの負担が少なく安全です。

復元したファイルが壊れている / 一部しか表示されない

上書きや断片化により、完全には戻らないことがあります。「一部破損」マークの付いたファイルは、読める範囲だけが復元されています。

初回起動時に確認画面が出る

このアプリは Apple の署名と公証を受けているため、通常はそのまま起動できます。「開いてもよろしいですか？」と出たら「開く」を押してください（初回のみ）。
