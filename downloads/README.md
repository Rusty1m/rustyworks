# downloads/

配布用のアプリ本体（dmg）を置く場所。
GitHub Pages からそのまま配信される。

    https://rustyworks.jp/downloads/Recoup-2.0.dmg

## 決めごと

**ファイル名にバージョンを入れる。** 理由は2つ。

- 同じ名前で差し替えると、CDN や利用者のブラウザが古い版を返すことがある
- 「何を落としたか」が URL で分かる

LP のダウンロードリンクは、リリースのたびに書き換える。
手間は1行だが、キャッシュ事故を確実に避けられる。

## 置く前に必ず確認すること

**ライセンス判定が入ったビルドであること。**

    strings Recoup.app/Contents/MacOS/Recoup | grep polar.sh

これが空なら、課金判定の無いビルド。**そのまま置くと製品を無償配布することになる。**
2026-08 に、判定前の 1.1 を置きかけて気づいた。

あわせて、署名・公証・ステープルが済んでいることも確認する。

    spctl --assess --type execute --verbose=2 Recoup.app
    xcrun stapler validate Recoup.app

## 容量について

このリポジトリは git 管理下なので、置いたファイルは履歴に残り続ける。
消しても履歴からは消えない。**古い版を整理する目的で置き直さないこと。**
1回あたり 4〜5MB なので、通常のリリース頻度では問題にならない。
