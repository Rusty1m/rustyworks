取扱説明書のための
2ペイン Markdown ビューアー

.md を開くだけで、左に項目・右に本文の閲覧画面になります。 設定もビルドも要りません。

HTML 1ファイル インストール不要 通信しません Mac / Windows / Linux

サンプルを選んでください

下の窓の中で、実物がそのまま動いています
DocPane
デモは画面の広い端末でご覧ください。
それでも開く

左の項目をクリックすると右が該当箇所へ移動します。ツールバーで見出しレベル・表示スタイル・ 「連続 / ページ」を切り替えられます。お手元の .md をこの窓に ドラッグしても試せます（このデモでは保存・書き出しはできません）。

項目に何を出すか選べる

H1〜H4 のどれを項目として拾うかを切り替えられます。階層があれば入れ子で並び、折りたたみもできます。

2通りの読み方

全文を続けて読む「連続」と、1項目＝1ページで紙の取説のようにめくる「ページ」を切り替えられます。

書き手が指定できる

ファイルの先頭に数行書くだけで、項目のレベル・表示スタイル・開いたときの状態を指定できます。

配布用に1ファイルへ

文書と画像を埋め込んだ HTML を書き出せます。渡した相手は、ダブルクリックするだけで読めます。

使っていただいています

掲載のご許可をいただいたものだけを載せています。
