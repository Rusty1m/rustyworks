UADB Privacy Policy

UADB（Universal Asset Database）は、プロジェクトアセットの検索・整理・タグ管理を行う Unity エディタ拡張です。

Last updated: 2026-07-25

1. 収集する情報

RustyWorks は、UADB を通じて個人情報、利用統計、解析データ、広告識別子を収集しません。UADB には、ユーザー追跡、広告SDK、解析SDK、テレメトリ送信の仕組みは一切含まれていません。

2. ローカルに保存される情報

UADB は Unity エディタ拡張として動作し、以下の情報をお使いの環境内にのみ保持します。

  • アセット一覧・検索のための索引情報
  • ユーザーが付与したタグ
  • 並び順、表示列、選択状態などの表示設定

これらはお使いの Mac／PC およびプロジェクト内に留まり、開発者のサーバーへ送信されません。

3. プロジェクトファイルの扱い

UADB は、アセットの一覧表示・検索・タグ管理のためにプロジェクト内のアセット情報を読み取ります。

非破壊的な運用を前提としており、ユーザーが明示的に操作しない限り、元のファイルを移動・改名・削除することはありません。

4. ネットワーク通信

UADB はネットワーク通信を行いません。ツール内に通信処理は実装されていません。

したがって、プロジェクトの内容やアセット情報が外部へ送信されることはありません。

5. お問い合わせ

このプライバシーポリシーに関するお問い合わせは、rustyworks.games@gmail.com までご連絡ください。

English Privacy Policy

UADB (Universal Asset Database) is a Unity Editor extension for browsing, searching, and tagging project assets.

1. Information We Collect

RustyWorks does not collect personal information, usage statistics, analytics data, advertising identifiers, or tracking data through UADB. UADB contains no user tracking, advertising SDK, analytics SDK, or telemetry of any kind.

2. Information Stored Locally

UADB runs as a Unity Editor extension and keeps the following only within your own environment.

  • Index data used to list and search assets
  • Tags you assign
  • View preferences such as sort order, visible columns, and selection state

This data stays on your machine and inside your project. It is not sent to RustyWorks servers.

3. Project Files

UADB reads asset information from your project in order to list, search, and tag assets.

It is designed for a non-destructive workflow and does not move, rename, or delete your files unless you explicitly ask it to.

4. Network Communication

UADB does not communicate over the network. No networking code is implemented in the tool.

Consequently, no project contents or asset information leave your machine.

5. Contact

For questions about this privacy policy, contact rustyworks.games@gmail.com.
