ShelfNavigator 取説 / Manual

登録したフォルダを索引して、まとめて閲覧・検索する macOS 用アプリ。

Last updated: 2026-07-25

はじめに

ShelfNavigator は、登録したフォルダを索引して、まとめて閲覧・検索するアプリです。ファイルを移動したりコピーしたりはしません。

1. フォルダを登録する

サイドバー下部の Add Folder…（または ⌘O）でフォルダを選びます。内蔵・外付け・ネットワークのいずれでも構いません。

登録すると索引（スキャン）が始まります。完了するとサイドバーに件数が表示されます。複数登録すると、All Files で全部が1つの一覧になります。

2. 表示を切り替える

  • タイル表示（T）— サムネイルを並べる。下部のスライダーで大きさを変更
  • プレビュー表示（P）— 1つを大きく表示し、下部のフィルムストリップで移動
  • 上部の種類フィルタで、画像・動画・テキストだけに絞り込み

3. 探す

検索欄には、普通の言葉のほか、次のような指定が使えます。

  • name: folder: ext: kind: tag:
  • size>10mb w>=1920 h<=1080 duration>60
  • modified:2024 created:2024-03
  • AND OR NOT（大文字）、-語 で除外、"引用符" で語順を固定
  • 範囲は size:1mb..2mb のように指定

フィルタボタンからは、サイズ・解像度・長さ・日付をGUIで指定できます。Finder タグはサイドバーから選べます。

4. 選択する

  • クリック — 単一選択
  • ⇧クリック — 範囲選択
  • ⌘クリック — 追加・解除
  • ⌘A — すべて選択
  • 矢印キーで移動、⇧＋矢印で選択を拡張

5. 開く・表示する

  • Return または ダブルクリック — 既定のアプリで開く
  • Space — 動画の再生／一時停止
  • ⌘⇧R — Finder で表示
  • I — 情報パネルの表示切替

設定の「開くアプリ」で、種類ごとに使うアプリを指定できます。macOS の既定は変更されません。

6. 重複を探す

ツールバーの Duplicates（⌘⇧D）で、登録した全フォルダを横断して重複を検出します。名前ではなく内容で比較します。

結果画面では、残すファイルを選んでから他をゴミ箱へ移動できます。移動の直前にもう一度バイト単位で照合するので、内容が変わっていたものは自動的に除外されます。

「Duplicate」タグを付けるだけにして、後で Finder で確認することもできます。

7. 削除と取り消し

⌘⌫ でゴミ箱へ移動します。ShelfNavigator がファイルを完全に消去することはありません。

直後であれば ⌘Z で元の場所に戻せます（同じ起動中のみ）。それ以降は Finder のゴミ箱から手動で戻してください。

8. 設定

  • ホバーで動画を再生 — タイルにカーソルを乗せたときのプレビュー再生
  • サムネイルのメモリ — 256MB〜4GB。多いほどスクロールが速く、メモリを使う
  • 開くアプリ — 画像・動画・テキストごとに指定

困ったとき

  • 一覧に何も出ない — 上部の種類フィルタや検索条件が残っていないか確認してください。絞り込み中はその旨がバーに表示されます
  • フォルダに「アクセス許可が必要」と出る — 外付けを繋ぎ直したか、macOS の許可が切れています。その項目から再度アクセスを許可してください
  • サムネイルが出ない — 破損したファイルや、拡張子と中身が食い違うファイルでは出ないことがあります
